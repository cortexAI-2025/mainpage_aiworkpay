# AIWorkPay — site institutionnel

Landing page commerciale d’AIWorkPay : agents autonomes spécialisés pour TPE/PME et orchestration de micro-missions humaines.

## Aperçu local

```bash
python3 -m http.server 8080
```

Puis ouvrir `http://localhost:8080`.

## Publication

Le site est statique et compatible avec GitHub Pages. Le fichier `CNAME` configure `aiworkpay.fr` comme domaine personnalisé.
